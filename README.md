# Kennel

**The package store for the [Bozzard](https://github.com/kaz0r/Bozzard) game engine.**
Named for Bozz.

A Kennel package bundles native binaries, Rhai scripts, typed assets and supporting files
for a Bozzard game. Before a package is listed here, Bozzard itself checks it:

- its scripts compile against the engine's script API;
- its assets load through the engine's own loaders;
- every file matches the SHA-256 recorded in its manifest.

Binaries from other vendors aren't re-hosted. Kennel downloads them from their upstream
source and verifies them against pinned hashes.

## Install a package

Kennel ships with Bozzard's `bozzard-project` tool:

```sh
bozzard-project kennel list                         # browse; add a word to search
bozzard-project kennel info steam                   # the full manifest
bozzard-project kennel install steam path/to/game   # into game/kennel/steam/
bozzard-project kennel verify path/to/game          # re-hash everything installed
bozzard-project kennel remove steam path/to/game
```

From an engine checkout, use `cargo run -p bozzard-project -- kennel …`.

- **Install location.** A package installs into `<project>/kennel/<name>/` and is recorded
  in `<project>/kennel.lock.json`. Scenes use package scripts and assets through their own
  asset catalog, for example
  `"steam/player": { "kind": "script", "path": "../kennel/steam/scripts/player.rhai" }`.
- **Registry.** Kennel reads this repository's `main` branch by default. To choose another
  registry, pass `--registry <folder|url>` or set `BOZZARD_KENNEL_REGISTRY`. To get an
  install you can reproduce, pin a commit or a release tag:
  `https://raw.githubusercontent.com/Bozzard-Engine/bozzard-plugin-library/steam-v1.0.0`.
- **Fresh pushes.** Right after a push, GitHub's raw file server can briefly serve an older
  `index.json`. If an install reports a manifest checksum mismatch, retry it or pin a commit.

## How a registry is laid out

```text
index.json                     generated by `kennel index`: name → version, summary, manifest hash
schema/pkg.schema.json         JSON Schema for manifests (editor completion)
schema/index.schema.json       JSON Schema for the index
packages/<name>/<name>.pkg.json
packages/<name>/…              every file the manifest lists, except upstream-sourced bins
```

Hashes chain together. `index.json` pins each manifest, each manifest pins each of its
files, and a binary with a `source` also pins its upstream archive. [SPEC.md](SPEC.md)
defines the format.

## Publish a package

1. Create `packages/<name>/` containing `<name>.pkg.json` and the package's files. Copy
   [`packages/steam`](packages/steam) as a starting point. Add
   `"$schema": "../../schema/pkg.schema.json"` to get editor completion.
2. List every file with its `bytes` and `sha256`. A folder may contain nothing the manifest
   doesn't list, and the check fails on any unlisted file.
3. Run the index and the check from a Bozzard checkout:
   ```sh
   cargo run -p bozzard-project -- kennel index  path/to/bozzard-plugin-library
   cargo run -p bozzard-project -- kennel check  path/to/bozzard-plugin-library --fetch
   ```
4. Open a pull request. CI runs the same check, and it fails if a package's files changed
   without a `version` bump.
5. After merging, tag the release `<name>-v<version>`.

## Trust

Checksums show that you received exactly what this registry published. They aren't
signatures. Package scripts run as game code, so review a package before you depend on it.
